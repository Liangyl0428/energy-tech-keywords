# 词典覆盖率统计（1,811 词条 → 论文 / 专利 / 政策）

统计日期：2026-10-31（纳入 2026 专利后重算）。本统计使用 `energy-topic-hotspots` 仓库的匹配实现（词条级 Aho-Corasick + 文档级去重）复算，词表即本仓库 `subtopics/` 下的 33 个子方向 CSV（1,811 词条）。口径与 `src/energy_hotspots/term_hotspots/extract_counts.py` 一致：
文档级去重（每篇文档对每个词条至多计 1 次）、父子词条最长匹配抑制、短缩略语大小写敏感（CO ≠ Co）、
英文复数与分隔符归一。**命中 = 标题（+摘要/全文）中出现该词条任一变体**。

## 说明

1. 命中率高是正常的：词典本身就包含"电力系统 / 储能 / 电池 / 可再生能源 / 电极 / 氧化物"这类
   覆盖极大的词条，能源领域文档自然大量被它覆盖。覆盖率**不代表**这些文档都对某个具体技术方向有用——
   真正做热点判别时还要过 `config/hotspot_rules.json` 的背景词、跨域泛化、规模与增速门槛。
2. 若只看"非背景词"（排除近一年文档频率 ≥2.5% 的领域通用词）的命中量，会显著低于上表；
   该口径可按需另算。
3. 论文分母有两个：全库 4,831,088（跨 27 年）与本文分析窗 1,754,329（2021–2026）。
   引用"占总量百分比"时请说明用哪个分母。
4. 机器可读的分年、分来源与词条级统计见 [`stats/`](../stats/)：
   `coverage_by_source.csv`、`coverage_by_year.csv`、`term_hits_by_year.csv`。
